DigiRisk Protect website files

Files:
- index.html: website structure/content
- style.css: styling and responsive layout
- script.js: demo tool interactions

How to run:
1. Keep all three files in the same folder.
2. Open index.html in your browser, or open the folder in Visual Studio Code.
3. In VS Code, you can use the Live Server extension and choose "Open with Live Server".

Important:
The tools are educational front-end demos. They do not perform live threat-intelligence lookups,
verify whether a website is safe, or check real data-breach databases. Do not enter passwords
or other sensitive information.
